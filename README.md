# TeleCrypt Synapse server container

Reproducible TeleCrypt Synapse image builder. The image combines an exact upstream Synapse
release with the pinned TeleCrypt fork inputs and the latest published TeleCrypt policy wheel
selected once by the image workflow.

This repository contains source and build metadata only; runtime configuration and credentials are
provided by the deployment environment. See [`LICENSE`](./LICENSE) and
[`THIRD_PARTY_NOTICES.md`](./THIRD_PARTY_NOTICES.md).
